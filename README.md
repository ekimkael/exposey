# Onyx

A single-screen React Native reproduction of a "Slash"-style login screen:
a fanned gold/silver/black card-stack hero that shrinks in lockstep with
the keyboard as you focus the email/password fields, floating-label text
fields, and a Sign In button that lights up once both fields have content.

Built to match a reference screen-recording frame-by-frame (idle state,
keyboard-focus shrink, and dismiss-back-to-idle).

## Requirements

- Node.js, npm
- Xcode + iOS Simulator (this app targets iOS; Android hasn't been verified)
- CocoaPods (`gem install cocoapods` if you don't have it)

## Install & run

```bash
npm install
npx expo run:ios
```

This does a native build (CocoaPods + Xcode), not just `expo start` —
the app has no `ios/`/`android/` folders checked in (generated by
`expo prebuild`, which `expo run:ios` triggers automatically).

## Platforms

- **iOS**: primary target, verified in Simulator.
- **Android**: not verified. The keyboard-shrink hook falls back to
  `keyboardDidShow`/`DidHide` (Android has no reliable "will show" event),
  so the shrink will trail slightly behind the keyboard instead of running
  concurrently with it.
- **Web**: not a target for this screen (native keyboard-avoidance behavior
  doesn't apply).

## Known limitations

- The native "Passwords" QuickType autofill bar (visible above the keyboard
  in the reference video) only appears with real saved credentials in the
  Simulator's keychain — untested with actual autofill data.
- The card-stack hero is hand-drawn with `expo-linear-gradient` + `View`s,
  not an image asset — colors/rotation are visually matched, not pixel-exact
  to any real card art.
